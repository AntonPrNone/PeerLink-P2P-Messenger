Как сделать ссылки рабочими

Почему возникает ошибка 404?

Когда вы открываете файл с диска (file:///C:/Users/...), на другом компьютере или телефоне этого диска не существует. Ссылки работают только тогда, когда HTML размещен на веб-адресе (https://...).

3 бесплатных способа получить веб-ссылку за 1 минуту:

  1. Netlify Drop: перейдите на app.netlify.com/drop и просто перетащите туда этот файл index.html мышкой. Вы сразу получите постоянный HTTPS-адрес.
  2. GitHub Pages / Cloudflare Pages: загрузите файл в бесплатный репозиторий — сайт заработает автоматически.
  3. Без хостинга вообще: просто отправьте файл index.html собеседнику через Telegram/диск. Вы оба открываете его и соединяетесь через кнопки «Скопировать код» или QR.
